01 / ABOUT

Software with a practical center.

NEXUS brings useful commands and system tools together in a personal terminal assistant built to evolve one module at a time.

Written in Python for Linux Mint, it pairs a command router and a small modular core with a distinct terminal interface. Commands handle built-in actions; plugins add focused utilities without making AI the center of the system.

The project has grown through successive releases—from its initial boot and kernel, through core and interface work, to an optional AI framework.

06 / GET STARTED

Start with the source.

NEXUS is a Python project for Linux. Clone the repository, install its listed dependencies, then launch the entry point.

Read the full documentation ↗

LOCAL INSTALLATION

git clone https://github.com/tiagoalmeida1605/NEXUS-Networked-Executive-Intelligence-System-.git
cd NEXUS-Networked-Executive-Intelligence-System-
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 nexus.py

Requires Python 3.10 or newer. Dependencies: Rich and psutil.
